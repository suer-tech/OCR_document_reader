# Главная задача проекта

При работе над паспортами сначала прочитай `OCR-document-parser/docs/PASSPORT_QUALITY_CONTEXT.md`.

Главная задача пользователя — улучшение качества всей системы обработки российских паспортов: от выделения и ориентации страниц до контейнеров, OCR и проверок по справочникам. Установка моделей и отдельные эксперименты являются средствами, а не конечным результатом.

Продолжай цикл: найти причину ошибки → исправить → проверить на визуально размеченных изображениях → сравнить с исходным вариантом → зафиксировать результат и следующий шаг. Не объявляй рост качества по совпадению с названием папки, валидному формату или одному попаданию в справочник.

В рабочий API пока не подключать. Не отправлять паспортные изображения во внешние сервисы без соответствующего разрешения; локальные эксперименты уже разрешены. Обращения к DaData для кода подразделения и названия органа выдачи пользователь разрешил ранее.

## Тестирование OCR

При написании, изменении или запуске тестов `OCR-document-parser`, проверке регрессий и разборе покрытия применяй скилл [ocr-testing](.agents/skills/ocr-testing/SKILL.md). Перед выбором тестов определи все затронутые поля, профили и исходы ветвей.

Для задачи по одному профилю запускай тесты его актуальной конфигурации и затронутых ветвей общего кода. Например, для РТК-3 выбирай `rtk3` и его проверки API. РТК и РТК-2 проверяются в собственных задачах или при изменении общего поведения, которое их затрагивает.
