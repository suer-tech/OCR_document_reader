# Заявление на банкротство

Тип и профиль: `bankruptcy_application`, версия 2.2, режим `llm_header`.
По поручению пользователя извлечение полей переключено на RouterAI,
`google/gemini-4-argon`. Изменение действует в локальном сервисе; рабочий сервер
не обновлялся. Swagger: http://127.0.0.1:8000/docs.

PDF с текстовым слоем читается напрямую, предпочтительно через PyMuPDF,
резервный читатель — pdfplumber. DOCX читается из OOXML: абзацы и таблицы в порядке
документа, без удалённых фрагментов. Изображения таких документов не отправляются
модели; Argon получает извлечённый текст. PDF без текста, смешанный PDF (часть
страниц без буквенного текста) и фото передаются непосредственно Argon как
изображения всех страниц в исходном порядке. Страницы PDF рендерятся локально;
модель сама читает шапку и извлекает поля в одном запросе. Промежуточный OCR
Gemini 2.5 и резерв Tesseract для этого профиля не вызываются.
Невалидные, зашифрованные, чрезмерно большие в распакованном виде и пустые либо
состоящие из изображений DOCX отклоняются явно.

Обработчик `services/bankruptcy_application_llm.py` возвращает прежние 16 полей
объединения `passport_main` и `passport_registration`: серия и номер паспорта,
фамилия, имя, отчество, пол, дата и место рождения, дата выдачи, код подразделения,
кем выдан, адрес регистрации, индекс, регион, населённый пункт, улица.
Объекты сохраняют `value`, `confidence`, `reasoning`, `source`, `extraction_method`.
Теперь `source=bankruptcy_llm`, `extraction_method=llm`. Argon заполняет
`confidence` отдельно для каждого поля: конечное число от 0 до 1 включительно,
также при `value=null` (уверенность в отсутствии/невозможности установить значение).
Это самооценка модели, не проверенная вероятность правильности. Низкая confidence
сама по себе не запускает повтор; условия повторов и расчёт quality не менялись.
Если значение отклонено локальной проверкой, публичная confidence очищается до
`null`; исходная оценка сохраняется как `model_confidence` в JSON версии результата.
При полном сбое модели оценки остаются `null`. Старые результаты не обновляются.

Модель выбирает дословный блок «Должник:» / «Заявитель:» до заголовка заявления
и выдаёт значения с цитатами. Тело, приложения, представитель, кредиторы,
корреспонденция и фактическое проживание не должны заполнять пропуски в шапке.
Локально проверяются принадлежность цитат исходному блоку, поддержка значений
цитатами и форматы. Различие пробела и переноса после дефиса при сравнении цитат
не считается изменением текста. Для изображений цитаты и шапка являются
транскрипцией самой модели; проверка их согласованности не доказывает правильность
визуального чтения. Такой результат требует сверки с изображением. В TextVersion
сохраняется прочитанная моделью шапка, а не полный текст всего скана. Локальный парсер не подставляет значения и
не используется как резерв при сбое модели.

- Паспорт РФ: серия 4 цифры, номер 6 цифр; ведущие нули сохраняются.
- Иностранный паспорт: полный номер, серия `null`; код подразделения необязателен.
  Вид паспорта сохраняется внутри `passport_number.passport_kind` для проверок.
- Пол определяет Argon по явному значению либо однозначному ФИО с пояснением
  в reasoning. Локальный `fio_gender` в этом пути не вызывается.
- Адресные части и индекс подтверждаются извлечённым адресом регистрации.
  Индекс без явного указания остаётся `null`; справочные запросы не выполняются.
- После первого запроса выполняются максимум 3 дополнительных раунда только
  для пустых `required:true` полей, с учётом исключений иностранного паспорта.
  Заполненные поля фиксируются. Необязательные пустые поля не повторяются.
  В режиме изображений исходные страницы прикладываются к каждому повтору,
  рендерятся один раз; выбранная шапка остаётся фиксированным контекстом.
  Отсутствующее обязательное значение остаётся `null` и требует ручной сверки.
  При терминальном отказе провайдера повтор прекращается; локальной подмены нет.

Загрузка: POST `/documents/upload`, `document_type=bankruptcy_application`, PDF
или DOCX, новый уникальный `idempotency_key` на каждую новую обработку. Повтор
старого ключа возвращает прежний результат, в том числе полученный локальным
парсером. Автоклассификация без явного типа использует прежний классификатор.

В локальной базе сохраняются исходный файл, версия извлечённого текста и версия
структурированного результата. В JSON структурированной версии дополнительно
сохраняются модель, версия промпта, цитаты, исходное значение модели и счётчик
повторов, `input_mode=text|vision`. Для изображений версия промпта
`bankruptcy_header_argon_vision_v2`, для текста — `bankruptcy_header_argon_v2`.
Публичный FieldValue остаётся совместимым. MLflow и артефакты текущего
запуска находятся локально, Langfuse отключён. Старые результаты не переписываются.
Результаты модели ещё не являются правильными метками: будущему локальному
обработчику нужны несколько сотен документов с проверенными человеком полями.

## Проверка

Моковые тесты нового пути проверяют отсутствие локального резерва, сохранение
16 полей, цитаты, иностранный номер, максимум 3 повтора обязательного поднабора
и отсутствие повторов необязательных полей:

`.venv/Scripts/python.exe -m pytest tests/services/test_bankruptcy_application_llm.py -q`

Для тестов задавайте `OCR_ROUTER_AI_API_KEY=offline-test-key`.
`scripts/check_bankruptcy_applications.py` оставлен как отдельный эксперимент
старого локального парсера; он не проверяет активное извлечение Argon. Работа над
локальным извлечением отложена до накопления проверенных документов.
История локальных прогонов и живой проверки Argon сохранена вне Git в
`../../runs/bankruptcy_new_documents_20261106/` и
`../../runs/bankruptcy_argon_20261106/REPORT.txt`. Эти материалы содержат
персональные данные и должны оставаться в локальном хранилище.

Проверка прямого чтения скана: `../../runs/bankruptcy_argon_vision_20261106/REPORT.txt`.
