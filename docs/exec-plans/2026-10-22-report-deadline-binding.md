# Срок отчёта: привязка поручений и согласованность

Ветка `codex/court-regex-jev-2026-10-20`, исходная база `4124e7c`.

## Изменения

- Разделены новые временные поручения внутри одного абзаца через точку с запятой; перечисление объектов с общим сроком сохраняется.
- Поддержана готовая дата до упоминания управляющего, включая дату окончания, явно указанную как срок подачи отчёта.
- Для selective LLM добавлено обязательное основание `deadline_basis`: explicit_date, date_reference, relative_advance, not_found, ambiguous. Общая проверка LLM и окончательного объединения вычитает 10 дней только для relative_advance. Неизвестная конструкция даты не превращается в принудительное вычитание.
- Неоднозначная ссылка «к назначенной дате» без текущего назначения заседания явно требует проверки.
- Противоречащие предложения JEV по флагу и дате переоткрываются совместно, с индивидуальными промптами. Итоговая пара false + непустой срок не может пройти автоматическое принятие. LLM повторно JEV не проверяется.
