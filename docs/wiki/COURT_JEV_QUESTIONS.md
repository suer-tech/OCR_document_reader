## Варианты по значению и основанию

Для булевых признаков и дат формулировка уточняется по кандидату.

- `early_report_required` = `True`: Обязал ли суд управляющего заранее представить отчёт по текущему делу?
- `early_report_required` = `False`: Верно ли, что суд не возложил на управляющего обязанности заранее представить отчёт по текущему делу?
- `procedure_end_date_is_calculated` = `True`: Вычисляется ли дата окончания текущей процедуры по назначенному сроку в месяцах?
- `procedure_end_date_is_calculated` = `False`: Указана ли дата окончания текущей процедуры в документе явно?
- `procedure_end_date_source` = `explicit_date`: Указана ли в документе точная дата окончания текущей процедуры?
- `procedure_end_date_source` = `explicit_duration`: Назначен ли текущей процедуре явный срок в месяцах без точной даты окончания?
- `procedure_end_date_source` = `not_found`: Верно ли, что в документе нет ни даты окончания текущей процедуры, ни назначенного ей срока в месяцах?
- `next_session_date` = `01.01.2027`: Назначено ли следующее заседание или рассмотрение отчёта текущего дела на дату "01.01.2027" по документу?
- `next_session_date` = `01.01.2027`: Подтверждается ли дата "01.01.2027" как дата окончания текущей процедуры при отсутствии явно назначенной даты следующего рассмотрения по документу?
- `resolutive_part_date` = `01.07.2026`: При отсутствии отдельной даты резолютивной части соответствует ли дата "01.07.2026" дате текущего решения с разделом РЕШИЛ?
- `procedure_end_date` = `01.01.2027`: Соответствует ли дата "01.01.2027" окончанию текущей процедуры, рассчитанному по назначенному сроку в месяцах от даты текущего акта?

Отдельные вопросы не используют результаты других вопросов как факты.
Зависимости подтверждений проверяет код маршрута. Результаты LLM в JEV не отправляются.
